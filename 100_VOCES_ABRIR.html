¿Por qué no se crean salas con el servidor de Python?

python -m http.server solo muestra archivos: no ejecuta la API ni la base de datos de las salas. Para una sala compartida usa la web publicada con acceso autorizado, o instala las dependencias con npm ci, ejecuta npm run build, prepara la base local con npm run db:local y después inicia npm start -- --port 8787 desde el repositorio y abre http://127.0.0.1:8787. Otros dispositivos necesitan una dirección de servidor accesible para ellos; 127.0.0.1 apunta a cada dispositivo, no a tu equipo.

      CONSULTA / PALABRAS PARA LEER LOS DATOS

      Un pequeño glosario.

      Vuelve aquí cuando una unidad o un concepto te impida interpretar una cifra.

      Porcentaje (%) y tasa
      Una proporción expresada sobre cien. Una tasa de 59,7 % significa 59,7 por cada 100 registros del universo definido; no es un conteo de personas en esta imagen.
      Puntos porcentuales (pp)
      La resta entre dos porcentajes. Pasar de 62,4 % a 59,7 % equivale a −2,7 pp, no a −2,7 % de cambio relativo.
      Cambio relativo (%)
      La diferencia dividida entre el valor inicial, multiplicada por 100. De 62,4 % a 59,7 %: (59,7 − 62,4) / 62,4 × 100 ≈ −4,3 %.
      Denominador y CCPC
      El denominador es el total usado para calcular una proporción. En estas tasas CCPC (Conteos Censales de Participación Ciudadana), se usan registros con voto/no voto definido; consulta las exclusiones en las fuentes.
      No participación y complemento
      Se calcula como 100 % menos la tasa de participación, con el mismo denominador. No equivale a conocer los motivos de quienes no votaron.
      Ámbito y elección comparable
      El ámbito indica si el dato corresponde a México, una entidad o un grupo de edad. Para estudiar cambios, compara la misma población y elecciones del mismo tipo: presidenciales con presidenciales o intermedias con intermedias.
      Escenario hipotético
      Un valor inventado para explorar una cuenta. Los escenarios A y B no son predicciones ni estimaciones del efecto de una campaña.
      Media y respuestas ficticias
      La media es la suma de las respuestas dividida entre su cantidad. El error absoluto medio promedia cuánto se aleja cada respuesta del dato oficial, sin compensar errores positivos y negativos. En el ensayo las respuestas son simuladas y no describen a una población real.
      Evidencia, fuente y causalidad
      La evidencia es el dato documentado; la fuente permite consultar su origen y método. Una diferencia entre tasas no demuestra qué la causó.
